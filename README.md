# 🤟 Smart Sign – ASL Hand Gesture Recognition
## Main repo for DEPI graduation project "Team 1"

## 📘 Overview
Smart Sign is a real-time ASL (American Sign Language) hand gesture recognition system built using Computer Vision and Deep Learning.
The system predicts ASL letters from webcam video using trained CNN-based models and supports a future extension for full word/sentence recognition using video keypoints.

This project was developed as a DEPI Graduation Project in the AI & Data Science – Microsoft Machine Learning Engineer Track.
---

## 🚀 Features
- Real-time ASL letter recognition using webcam
- High accuracy models (up to 98.44%)
- Robust preprocessing + augmentation
- Lightweight deep learning architecture for fast inference
- Supports 27 ASL classes (A–Z + space, delete, nothing)
- Ready for deployment with Streamlit or Flask
- Future support for word-level dynamic gestures

---

## 🧠 Models Used
*✔ Supervised Models*
- LeNet-50 (98.44% accuracy)
- Custom CNN
- MobileNetV2
- ResNet50 (fine-tuned)

*❌ Not suitable for real-time (but tested)*
- XGBoost
- Random Forest
- Logistic Regression

*🎬 Dynamic Mode (In Development)*
- MediaPipe Keypoints + BiLSTM for full-word gestures

---


## ⚠️ Disclaimer
This system is designed for educational and research purposes only.
While it recognizes ASL letters with high accuracy, *it must not be used as a replacement for certified sign-language interpretation*.
Real-world usage may include errors due to lighting, angle, or gesture variations.

*Predictions may contain errors or inaccuracies.*
