# Smart Sign – Hand Gesture Recognition System
## Main repo for DEPI graduation project "Team 1"

A Real-Time ASL Hand Gesture Recognition Project (DEPI Graduation Project)

Smart Sign is a real-time sign language recognition system that uses computer vision and deep learning to translate ASL hand gestures into text. Built as a DEPI graduation project in the AI & Data Science – Microsoft Machine Learning Engineer Track, the system supports:

1. Letter Recognition Mode (Completed)

Recognizes static ASL alphabet gestures in real-time using CNN-based models.

2. Dynamic Gesture Mode (In Development)

Detects word-level gestures using video keypoints + BiLSTM models.
